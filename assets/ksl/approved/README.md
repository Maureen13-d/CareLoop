# Approved derived clip packs only.

Nothing in this folder until a Deaf signer has a written consent and a Deaf reviewer has approved the clip.
Store packs with Git LFS, or keep them outside git and point the registry at that storage.
Rendered `.mp4` and `.webm` files must be Git LFS pointers. Camera originals (`.mov` and the rest) are refused.
Signer photos and raw mocap are refused everywhere, including here.
